# Chromium 页面采集器

一个本地运行的 Chromium Manifest V3 扩展，用于采集当前标签页的 Fetch/XHR 网络记录、页面截图和备注。当前版本为 0.1.4。扩展不上传采集数据，也不自动遍历页面或提交表单。

## 安装

1. 下载或克隆本仓库。若使用发布包，先将 ZIP 解压到本地目录。
2. 在 Chrome 打开 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”。
3. 选择仓库中的 `extension/` 目录；若使用发布包，选择包含 `manifest.json` 的解压目录。

运行扩展的电脑无需 Node.js、本地服务器或其他依赖。更新文件后，在扩展管理页重新加载扩展。本项目不是签名的商店扩展；企业策略禁止加载或调试时，请联系管理员。

Chrome 是首要目标，清单声明最低 Chrome 版本为 105。Edge 和其他 Chromium 浏览器的可用性取决于其内核和扩展 API；尚未完成真实浏览器版本矩阵验证。扩展使用 `activeTab`、`debugger`、`downloads` 和 `storage` 权限，连接时浏览器可能显示调试提示。

## 使用

1. 打开已获准采集的页面，点击扩展图标，或按 `Alt+Shift+Y`。
2. 填写备注，点击“开始采集”。默认选中重载当前页面，启动时没有二次确认。不要在正在提交表单、执行交易或重载可能改变状态的页面使用。
3. 保持采集状态页打开，等待网络记录、截图和备注下载完成。网络采集最多等待 20 秒，页面 load 后会等待约 2.6 秒以记录短时请求；超时或未重载导致的初始请求缺失会在备注中标记。
4. 在终态点击“关闭并返回原页面”，关闭状态页并返回原标签页。原标签页已关闭时，只关闭状态页。

取消重载可保留当前页面状态，但只能记录开始采集后发生的请求，可能缺少初始页面请求。

## 输出

浏览器分别下载三个文件到下载目录下的同一个 `PageCapture` 子目录，不会自动压缩采集结果：

- `page.json`：顶层数组，每项只有 `request` 和 `response`。保留实际发生的 Fetch/XHR 请求与响应及其 HTTP 方法，不限于 GET 或 POST。
- `screenshot-full.png`：页面当前已渲染内容的整页截图。超长页面整页截图失败时会尝试回退到当前视口；如果截图完全失败，该文件不会生成，状态页和备注会说明。
- `note.txt`：备注、采集元信息、统计、计时、请求类别和正文省略原因等诊断。接口诊断序号从 1 开始，与 JSON 数组顺序对应。

`response.bodySize` 是已知的正文传输字节数，无法可靠确定时为 `-1`。备注中的总传输量可能包含响应头。采集器不会自动滚动触发懒加载，默认重载也可能改变页面当前显示的内容。

## 范围与隐私

只导出浏览器分类为 Fetch 或 XHR 的请求；不记录 WebSocket/SSE 消息帧。扩展协议地址及浏览器可识别为扩展发起的请求会从记录中排除；浏览器未提供来源时，无法可靠识别普通 HTTP/HTTPS 地址背后的扩展请求。过滤只影响导出，不拦截网络请求。跨进程 iframe 和 Service Worker 发起的请求尚未在目标浏览器验证。

JSON、XML、纯文本和 GraphQL 响应可保存正文；二进制及其他类型只保留元数据。单条响应正文上限为 2 MiB，累计上限为 24 MiB，超限、未完成等情况会在备注中说明。multipart 和无法按支持的格式脱敏的请求正文会省略。

认证类请求头，以及 URL 查询参数、JSON 和 URL 编码表单中名称匹配常见敏感关键词的字段会脱敏。普通文本正文不做字段级脱敏，其他正文和截图仍可能包含敏感信息；分享前请检查所有文件。真实采集数据、截图、备注和凭据应保留在仓库外。

## 开发与打包

开发验证需要 Node.js；项目没有第三方 npm 依赖。在仓库根目录运行：

```powershell
npm test
npm run check
npm run package
```

`npm test` 运行 Node VM 回归检查，`npm run check` 检查扩展 JavaScript 语法；这些检查不能替代真实浏览器验证。`npm run package` 默认调用 Windows PowerShell 5.1。如果环境中只有 PowerShell 7，可直接运行 `pwsh -NoProfile -File scripts/package.ps1`。

打包从扩展清单读取版本，将 `extension/` 的内容打包为 `dist/chromium-page-capture-<version>.zip`，并生成同名 `.zip.sha256` 文件。打包不安装依赖、不上传文件。
